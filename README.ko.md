# ALIRA — C 소스코드로 만드는 소프트웨어 상세설계서

> 이 문서는 [README.md](README.md)의 한국어 번역입니다. 두 문서의 내용이 다를 경우 영문판이 기준입니다.

ALIRA는 코딩 에이전트 안에서 C 소스코드를 소프트웨어 상세설계서(SDD)로 만들어 줍니다. 프로젝트 폴더를 지정하고 견적을 승인하면, 함수별 요약·요구사항·입출력 명세·호출 관계·플로우차트를 담은 Word 또는 Markdown 문서를 내려받을 수 있습니다. 문서는 한국어로 작성됩니다.

ALIRA는 슈어소프트테크가 운영하는 호스팅 서비스입니다. 이 저장소는 에이전트를 서비스에 연결하는 서버 주소, 작업 절차를 안내하는 Skill, 문서로 구성됩니다. 실행 코드가 없고 ALIRA 서비스 자체도 포함하지 않습니다. ALIRA는 무료 체험이 있는 유료 서비스이며, MIT 라이선스는 이 저장소에만 적용되고 서비스에는 적용되지 않습니다.

생성된 문서는 엔지니어가 검토할 초안입니다. 사용하기 전에 코드와 프로젝트 요구사항에 맞는지 확인하세요.

## ALIRA가 더하는 것

| 필요 | ALIRA가 하는 일 |
|---|---|
| 기존 코드의 설계 문서 | 소스에서 함수별 요약, 요구사항, 입출력, 호출 관계, 플로우차트를 작성합니다. |
| 팀에서 쓸 수 있는 문서 | Word(`.docx`) 또는 Markdown(`.md`) 파일로 내보냅니다. |
| 큰 코드베이스 | 한 번에 최대 100개 함수를 생성하고, 파일이나 폴더 단위로 나눠 진행할 수 있습니다. |
| 문서 기반 답변 | 함수나 모듈에 관한 질문에 생성된 문서를 근거로 답합니다. |
| 사용량 통제 | 시작 전에 예상 사용량을 보여 주고 승인을 기다립니다. |

## 작업 흐름

1. 브라우저에서 ALIRA 계정을 연결합니다.
2. 폴더나 ZIP 파일을 고르고, 전송될 내용을 확인한 뒤 업로드를 승인합니다.
3. 견적을 확인하고 생성을 승인합니다.
4. 진행 상황을 확인하고, 요약을 읽고, 문서를 저장합니다.

## 설치

ALIRA 계정이 필요합니다. [웹사이트에서 만들 수 있습니다](https://alira-ai.ai/login?signup=1).

Claude Code에서:

```text
/plugin marketplace add SuresoftTechnologies/alira-ai-agent
/plugin install alira@suresofttech-alira
```

그다음 `/mcp`를 실행해 `alira`(`plugin:alira:alira`로 보일 수 있습니다)를 고르고 Authenticate를 선택해 로그인합니다.

Skill 없이 서버만 연결하려면 직접 추가합니다.

```text
claude mcp add --transport http --scope user alira https://alira-ai.ai/mcp
```

Skill 없이 쓰면 호출 순서와 승인 요청 시점은 에이전트가 정합니다. 서버는 그대로 견적을 돌려주고, 데이터를 바꾸는 도구에는 destructive 표시가 있어 이 표시를 따르는 클라이언트는 호출 전마다 확인합니다.

다른 MCP 클라이언트는 `https://alira-ai.ai/mcp`에 OAuth를 쓰는 원격 서버로 연결할 수 있습니다. 파일 업로드에는 Claude Code처럼 사용자 PC에서 셸 명령을 실행할 수 있는 에이전트가 필요합니다. claude.ai 채팅에서는 계정·작업·결과 도구를 쓰고 파일 다운로드 링크를 브라우저로 열 수 있지만 로컬 폴더는 올릴 수 없습니다.

## 요청 예시

응답은 AI 모델과 대화에 따라 달라질 수 있습니다. 결과가 기대와 다르면 더 자세히 요청해 보세요.

| 요청 | 동작 |
|---|---|
| `./firmware의 C 코드로 SDD 만들어줘.` | 승인 후 업로드하고 견적과 생성으로 이어집니다. |
| `ALIRA 사용량 얼마나 남았어?` | 플랜과 남은 사용량을 알려 줍니다. |
| `어디까지 진행됐어?` | 작업 진행 상황을 알려 줍니다. |
| `init_sensor는 무슨 일을 해?` | 생성된 문서를 근거로 답합니다. |
| `결과를 Word로 받아줘.` | 파일을 저장하고 위치를 알려 줍니다. |

## 이 플러그인이 실행하고 전송하는 것

플러그인은 훅, 스크립트, 백그라운드 프로세스를 추가하지 않습니다. 사용하면 다음 일이 일어납니다.

- 에이전트를 `https://alira-ai.ai/mcp`에 **연결**합니다. 브라우저에서 OAuth로 로그인하고, 토큰은 클라이언트가 보관합니다.
- 서버가 돌려준 **셸 명령을 실행**합니다. 업로드 명령은 `find`, `tar`, `curl`을 쓰고 PowerShell에서는 `tar.exe`, `curl.exe`를 씁니다. 다운로드 명령은 `mkdir`, `curl`, `ls` 또는 그에 해당하는 PowerShell 명령을 씁니다. 에이전트의 권한 확인이 그대로 적용되므로 실행 전에 명령을 검토할 수 있습니다.
- 업로드를 승인하면 **소스코드를 ALIRA 서버로 보냅니다.** `bash`로는 `.c`, `.h` 파일만 보냅니다. **PowerShell이나 ZIP 파일을 쓰면 폴더나 ZIP의 다른 파일도 전송되며, `.env`, `.ssh` 같은 숨김 파일과 숨김 폴더도 포함됩니다.** 서버는 `.c`, `.h` 파일만 남기고 나머지는 보관하지 않습니다. 자세한 내용은 [PRIVACY.md](PRIVACY.md)를 참고하세요.
- 문서를 기본적으로 `~/ALIRA/outputs/<project>/`에 **저장**합니다.

## 요구 사항과 요금

- ALIRA 계정. 조직의 플랜과 사용량이 적용됩니다.
- C 소스코드(`.c`, `.h`). 다른 언어는 지원하지 않습니다.
- 파일 업로드를 위한 사용자 PC의 셸.

ALIRA는 유료 서비스이며 월 플랜(Starter, Pro, Ultra)은 사용량 수준으로만 나뉩니다. 웹사이트에서 가입한 조직은 SDD 생성 1회(최대 15개 함수)와 Markdown 1회 다운로드를 무료로 체험할 수 있습니다. 플랜 선택과 결제는 웹사이트에서 브라우저로 합니다. [요금](https://alira-ai.ai/pricing)을 확인하세요. 코딩 에이전트 자체 요금은 별도입니다.

## Privacy Policy

이 플러그인을 사용하면 소스코드가 슈어소프트테크의 ALIRA 서버로 전송됩니다. 공개할 수 없는 코드를 올리기 전에 읽어 주세요.

- 소스코드는 승인한 뒤 업로드 단계에서만 PC를 벗어납니다. 업로드 방식별로 무엇이 전송되는지는 [PRIVACY.md](PRIVACY.md)에 있습니다.
- 업로드한 코드와 생성 파일은 문서 생성과 다운로드 제공에만 사용합니다. 재판매하거나 제3자와 공유하지 않으며 AI 모델 학습에 쓰지 않습니다.
- 문서를 생성하는 AI 모델은 슈어소프트테크가 운영하는 서버에서 실행됩니다.
- 업로드한 코드와 생성 파일은 기본적으로 마지막 사용일부터 30일 뒤 삭제됩니다. 내 계정에서 기간을 바꾸거나 언제든 삭제할 수 있습니다.
- AI 클라이언트는 파일 경로와 문서 내용이 포함될 수 있는 도구 결과를 해당 제공사의 약관에 따라 자사 모델로 보냅니다.

[PRIVACY.md](PRIVACY.md)와 [ALIRA SDD 개인정보 처리방침](https://alira-ai.ai/legal?doc=privacy) 전문을 읽어 주세요.
